100% Python Architecture

Built as a monolithic desktop application running multithreaded computer vision routines alongside local JSON data persistence.

UI & GUI Loop

PyQt6 / PySide6 event loop handling screen routing, user forms, and modal dialogs.

Camera Thread

OpenCV (cv2) background worker streaming 30 FPS video feeds.

Pose Engine

Ultralytics YOLOv8 extracting 17 body keypoints in real time.

Quick Start Guide

Instructions for cloning, compiling, and running the Raider Trainer application locally.

bash
$ git clone https://github.com/deepikaJirel/RaiderTrainer.git
$ cd RaiderTrainer
$ python -m venv venv
$ source venv/bin/activate # or venv\Scripts\activate on Windows
$ pip install -r requirements.txt
$ python main.py
